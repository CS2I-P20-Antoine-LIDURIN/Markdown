# Comment fonctionnent les workflows GitHub ?

Les workflows sont décrits dans des fichiers YAML.

Ces fichiers sont placés dans :

.github/workflows/

## Fonctionnement simplifié

1. Un événement se produit.
   - Exemple : un développeur envoie du code.

2. GitHub détecte l'événement.

3. Le workflow démarre automatiquement.

4. GitHub exécute les différentes tâches prévues.

5. Un résultat est affiché (succès ou erreur).

Les workflows GitHub sont des outils d'automatisation qui permettent de gagner du temps, d'améliorer la qualité des projets et de simplifier le travail en équipe.
