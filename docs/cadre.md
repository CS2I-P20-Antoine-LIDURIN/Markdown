# Dans quel cadre s'appliquent les workflows GitHub ?

Les workflows GitHub s'utilisent dans les dépôts GitHub.

Ils sont principalement utilisés dans le développement logiciel, mais aussi dans d'autres projets nécessitant des tâches automatiques.

Par exemple :

- Applications web
- Applications mobiles
- Jeux vidéo
- Sites internet
- Projets de documentation

Dès qu'une équipe travaille sur un projet hébergé sur GitHub, les workflows peuvent être utilisés pour automatiser certaines actions.
